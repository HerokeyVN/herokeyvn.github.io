# HerokeyVN visual design explorations

These prototypes are intentionally isolated from the Astro production page. They are static art-direction studies for review only; none imports Three.js or changes production routing.

- `concept-01-monolith/`: identity-first typographic monolith. A future service sculpture lives inside the `O` counter and behind the wordmark.
- `concept-02-ledger/`: warm editorial engineering ledger. A bounded inspection window reserves a stable stage for a future 3D system artifact.
- `concept-03-aperture/`: spatial black-field composition. A central aperture is the future 3D stage, with typography and the thread arranged around its gravity.

Each page contains a 100svh Hero and a complete Hero-to-About transition. The SVG thread is manually composed for the corresponding typography and split into back/front layers where it crosses glyphs.

Serve the repository root and open each `index.html` directly. Review captures are stored in `screenshots/` at 1440×900 and 390×844, plus one desktop transition frame per concept.
